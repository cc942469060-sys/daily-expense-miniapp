# 小日账 · 微信个人收支账本

原生微信小程序 v1.2.0，JavaScript + WXML + WXSS，无第三方运行依赖、无需服务器、无需登录。首次启动是空账本，不混入演示账单或资产。

## 如何运行

1. 打开微信开发者工具，选择「导入项目」。
2. 导入整个 `daily-expense-miniapp` 文件夹，也就是包含 `project.config.json` 的目录；不要单独导入 `miniprogram`。
3. 项目默认使用 `touristappid`。可在工具支持时选择测试号/游客模式进行本地调试；真机预览、上传和发布请换成自己的小程序 AppID。
4. 后端服务选择「不使用云服务」，点击编译。无需 npm install，也无需构建 npm。
5. 正式发布前，在微信公众平台完善名称、类目等资料，使用真实 AppID 预览并完成真机验收后，再按平台流程提交审核。

项目没有联网请求，不需要配置业务服务器域名。Node.js 仅用于运行开发检查和测试，不是小程序运行条件。

## 已实现的功能

- 首页：本月收入、净支出与结余，今日收支和笔数，支出预算进度、最近 8 笔记录。
- 快速记账：支出/收入切换，金额、对应分类、日期、时间、支付/收款方式、备注；支持补记、保存后继续记账。默认收入分类包括工资、奖金补贴、报销、红包、礼金、兼职副业、投资收益、其他收入。
- 账单详情：编辑、删除确认；支出支持累计退款登记，收入不能登记退款。修正收支类型时须重新选择分类，已有退款的支出需先修正并保存退款。
- 统计：日、周、月、年切换，日期选择、前后周期切换；本期收支与结余，按收入/支出查看总金额和笔数；支出显示日均，收入显示最大单笔。
- 收支趋势：收入和支出分别展示，周/月按日、年按月展示柱状图；柱子可进入对应日期、对应类型的明细。
- 分类统计：金额、百分比、进度条，收入和支出各自计算占比；点击分类查看本期对应类型明细；显示本期大额收支。
- 账单明细：全部/支出/收入、日期范围、分类、收支方式、备注/分类关键词筛选；收入带加号、支出带减号，日期分组分别汇总收支，按 100 笔分页加载。
- 分类管理：收入、支出分别新增、改名、换图标；删除分类时把历史账单迁移到同类型分类。每种类型至少保留一个分类，同类型内名称唯一。
- 支出预设：餐饮、交通、购物、住房、娱乐、医疗、学习、其他，以及保险、理财、贷款、旅行、长辈、礼金。支出礼金与收入礼金分别统计。
- 月预算：可设置金额，填 0 或留空关闭。
- 资产：底部「首页 / 统计 / 资产 / 我的」，展示总资产、总负债、净资产，以及资产和负债各自的分类占比。
- 账户：银行卡、支付宝、微信、股票、国债、黄金、基金/理财、现金、其他资产；负债包括信用卡、房贷、车贷、消费贷/分期、个人借款、其他负债。支持多个同类账户、手动金额更新历史、零余额归档与重新启用、独立分类管理、金额隐藏。
- CSV：导出全部账单，支持 Excel 阅读中文；正确转义引号、逗号和换行，处理公式前缀。
- JSON：备份/恢复全部账单、账户、金额更新历史、分类和设置；格式校验、替换前确认、保留恢复前副本。另可导出独立的 CSV 资产清单。

## 资产使用规则

1. 在「资产」添加账户，选择资产或负债、分类，填写名称、当前金额及金额日期。尾号和备注选填，同名账户可并存。
2. 所有金额均为人民币。银行卡、钱包填余额；股票、国债、黄金、基金等填手动核对的当前市值或估值；负债填当前未还金额（正数）。单账户支持 0—999,999,999.99 元。
3. 总资产、总负债汇总所有使用中账户，净资产 = 总资产 − 总负债，可为负数。列表筛选不改变顶部全局合计；归档账户金额必须为零。
4. 通过「更新当前金额」填写完整新金额，日期不早于上次金额日期、不晚于今天。可填写相同金额以更新核对日期。系统原子保存新金额与更新历史，失败则两者都不改变；超过 30 天未更新的账户显示提示。
5. 修改名称、分类、尾号或备注不产生金额更新记录。归档保留全部历史，可重新启用；仅尚未更新过金额的误建账户可确认删除。
6. 收入、支出、退款与账户余额独立，互不自动调整。转账后可分别更新两边余额；钱包内已单列的理财不要重复登记。金额变动不直接当作收益或收支。
7. 隐藏金额覆盖合计、分类金额与占比、账户列表、详情及金额历史；设置在重启后保留。点击「显示并更新金额」会显示可编辑的当前金额。导出的 CSV/JSON 仍保留真实金额。
8. 资产和负债分类各自新增、改名、更换图标；删除时只能迁移到相同类型分类，归档账户也会迁移。每类至少保留 1 个、最多 40 个分类。
9. 本版不接行情、不计算持仓收益或自动利息、不做借贷还款计划和净资产趋势。设计细节见 [资产设计](docs/assets-design.md)。

## 统计规则

1. 金额存为整数「分」，展示为人民币「元」。单笔金额为 0.01—9,999,999.99 元，最多两位小数。
2. 净支出 = 原支出 − 累计退款，结余 = 收入 − 净支出。退款继续扣减原支出日期的统计；本期结余是记账口径的收支差额，不是账户余额或按退款实际到账日计算的现金流。
3. 周从周一到周日；月和年使用自然月、自然年，支持闰年及跨年周。
4. 支出的当前周期日均按已过自然日计算，历史周期按全部自然日计算，包括无支出的日期。收入视图显示最大单笔收入。
5. 日期分组小计按当天的完整筛选结果计算，即便列表尚未加载完，也不会少算金额。
6. 完全退款的记录仍计入支出笔数，仍可从明细查询，支出分类占比按净支出计算；收入分类占比只使用收入总额。
7. 记账日期范围为 2000 年起至今天，不支持未来记录。默认分类及收付款方式参考相同收支类型下最近修改过的记录。
8. 月预算设置对所有月份采用同一金额，预算已用只计算净支出，收入不抵扣预算用量，暂不提供每月独立预算历史。
9. 收入按实际到账日期和实收金额记录，待发工资、待报销款暂不计入。报销作为收入时保留原垫付支出，不再把同笔款项登记为退款。例如同期垫付 500 元、报销到账 500 元，结余为 0。当前通过提示和备注区分，不自动关联或去重。
10. 自己账户之间转账不记收入或支出；收入中的投资收益分类记录实际收到的收益，不把本金转入或赎回当作收入。

## 导出和恢复

「我的 → 导出与备份」：

- **CSV**：分别导出账单或资产清单（含归档账户），用于 Excel 阅读；资产 CSV 包含当前金额但不包含金额更新历史，不能从 CSV 恢复。
- **JSON**：发送并保存版本 3 的完整备份，包含收支和资产数据；新备份需在支持资产的版本中恢复。请在设备之外保存文件；只生成设备内文件不等于完成外部备份。
- **恢复**：支持版本 1 的旧支出备份、版本 2 的收支备份和版本 3 的资产备份。确认后整体替换全部数据，不做合并。旧版备份没有资产账户，确认框会明确提示当前资产也将清空；取消不会修改账本。
- **恢复导入前副本**：可返回最近一次导入前的账单、资产、历史、分类和设置。导入后新增或修改的数据不会包含在该副本中，操作前会确认。

设备内生成的文件名固定为 `xiaorizhang-bills.csv`、`xiaorizhang-assets.csv` 和 `xiaorizhang-backup.json`，每次更新同名文件，避免重复导出占用空间。外部保存的副本请自行管理。

开发者工具的文件选择/发送能力可能受环境限制，JSON 文件导入和发送需要真机验收。取消发送不会更新「最近成功发送备份」时间。这个时间表示微信文件发送 API 返回成功，不表示文件已永久保存。

## 旧版本升级

增加保险、理财、贷款、旅行、长辈、礼金后，已有账本及旧备份会一次性补齐缺少的支出分类。同名支出分类保留原 ID、图标及历史关联；分类 ID 冲突时使用新的唯一 ID。升级标记随 JSON 备份保存，之后自行删除或改名不会被自动还原。若支出分类接近 40 个上限，只在剩余名额内补齐；未补齐的分类可在整理分类后手动添加。历史金额和预算不受影响，写入失败保留原数据。

首次运行优先读取版本 3 主存储键；不存在时，依次读取 v2、v1 旧账本并迁移。v1 账单和分类归为支出并增加收入分类；v1/v2 保留原 ID、金额、退款、日期、备注、预算及时间戳，同时增加默认资产分类、空账户及空金额历史。旧存储键保留为升级前副本；重复启动不会重复追加分类。已有较新版本数据损坏时不会退回陈旧旧账本。

升级写入失败会保留原数据并提示重试。旧副本会额外占用本地存储空间，本版不自动清理。导入前副本与升级前副本使用不同存储键，旧版有效的导入前副本也可以迁移恢复。

## 数据保存与限制

- 数据通过微信本地存储保存在当前设备。换手机、清理小程序数据等情况可能导致本地数据不可用，事先导出 JSON 备份。
- 主账本在一个存储键内写入，写入失败时保留上次成功的数据，并显示错误，不显示保存成功。
- 数据结构损坏时不自动重置，页面提供备份恢复入口。
- 本地存储有平台容量限制，实际可保存的记录数取决于备注长度和设备存储条件。接近容量上限的写入会报错，可先导出备份；账户归档保留历史，不释放存储空间。本版不提供云同步或清理历史。
- 当前结构每种收支类型最多校验 40 个分类（合计 80 个）、合计 50,000 笔记录，文件选择上限 8 MB。这些是结构/文件校验上限，不代表平台一定能存下对应数量。
- 资产额外支持最多 200 个账户（含归档）、20,000 条金额历史、资产与负债各 40 个分类；这些是数据校验上限，同样受本地实际存储容量限制。
- JSON/CSV 是可读明文文件，包含你的收支、资产和备注。页面隐藏金额不加密导出文件，备份文件请按自己的隐私需要保存。

## 开发检查

在项目根目录运行（推荐 Node.js 18 或更新版本）：

```sh
npm test
npm run check
```

若安装了微信开发者工具，可直接使用其附带的编译器检查全部模板与样式：

```sh
node scripts/native-check.js "微信开发者工具安装目录/code/package.nw/node_modules/wcc-exec"
```

`native-check.js` 只使用本地编译器，不启动 GUI、不上传项目。它不能替代模拟器渲染或真机验收。

## 真机验收清单

1. 新增 0.10、0.20 两笔，同一天总计应为 0.30。
2. 补记其他日期，确认日/周/月/年的明细与总额一致。
3. 编辑一笔金额，再登记部分或全部退款，确认列表和统计更新。
4. 新增分类，记账后删除该分类并迁移，确认历史金额不变。
5. 导出 CSV 检查中文、金额与备注；发送 JSON，再选取并恢复，确认账单、分类、预算一致。
6. 取消文件选择及文件发送，确认账本不变；恢复导入前副本，确认数据回退。
7. 关闭并重新进入小程序，确认本地账单仍在。
8. 同月记收入 8,000 元、支出 2,200 元，确认结余 5,800 元；设置预算 3,000 元，剩余应为 800 元，不受收入影响。
9. 在收入视图点击分类、趋势柱子，确认明细只包含对应收入；编辑收入不出现退款项；连续记账保留收入类型。
10. 收入、支出都新增同名分类，确认各自可管理；删除收入分类只允许迁移到其他收入分类。
11. 使用旧版 JSON 恢复，确认原金额、退款、预算不变；再导出新版 JSON，确认恢复后收支均完整。

12. 添加资产 160,000 元与负债 60,000 元，确认净资产 100,000 元；切换筛选不改变顶部合计。记一笔收入或支出后，资产金额保持不变。
13. 修改账户资料不增加金额历史；更新金额（包括同金额不同日期）新增历史。金额归零后可归档、重新启用；有更新历史的账户不能删除。
14. 隐藏金额后检查列表、分类占比、详情和历史，退出重进仍隐藏；主动编辑金额会显示当前金额，保存或取消后恢复隐藏。
15. 导出并恢复 v3 备份，确认资产、负债、更新历史和隐藏设置一致；恢复旧版备份需提示资产清空，取消保持数据，导入前副本可完整找回。

当前版本不包含云端同步、自动读取微信支付账单、多个账本、收支联动余额、待报销管理和自动识别小票。
