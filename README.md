# 小日账 · 微信个人消费账本

原生微信小程序第一版，JavaScript + WXML + WXSS，无第三方运行依赖、无需服务器、无需登录。首次启动是空账本，不混入演示账单。

## 如何运行

1. 打开微信开发者工具，选择「导入项目」。
2. 导入整个 `daily-expense-miniapp` 文件夹，也就是包含 `project.config.json` 的目录；不要单独导入 `miniprogram`。
3. 项目默认使用 `touristappid`。可在工具支持时选择测试号/游客模式进行本地调试；真机预览、上传和发布请换成自己的小程序 AppID。
4. 后端服务选择「不使用云服务」，点击编译。无需 npm install，也无需构建 npm。
5. 正式发布前，在微信公众平台完善名称、类目等资料，使用真实 AppID 预览并完成真机验收后，再按平台流程提交审核。

项目没有联网请求，不需要配置业务服务器域名。Node.js 仅用于运行开发检查和测试，不是小程序运行条件。

## 已实现的功能

- 首页：今日净消费、本月累计、今日笔数、月预算进度、最近 8 笔记录。
- 快速记账：金额、分类、日期、时间、支付方式、备注；支持补记、保存后继续记账。
- 账单详情：编辑、删除确认、累计退款登记。
- 统计：日、周、月、年切换，日期选择、前后周期切换、总金额、日均、笔数。
- 消费趋势：周/月按日、年按月展示柱状图；柱子可进入对应日期的明细。
- 分类消费：金额、百分比、进度条，点击分类查看本期对应明细；显示本期大额消费。
- 账单明细：日期范围、分类、支付方式、备注/分类关键词筛选，日期分组与小计，按 100 笔分页加载。
- 分类管理：新增、改名、换图标；删除分类时把历史账单迁移到另一分类。
- 月预算：可设置金额，填 0 或留空关闭。
- CSV：导出全部账单，支持 Excel 阅读中文；正确转义引号、逗号和换行，处理公式前缀。
- JSON：备份/恢复全部账单、分类和预算；格式校验、替换前确认、保留恢复前副本。

## 统计规则

1. 金额存为整数「分」，展示为人民币「元」。单笔金额为 0.01—9,999,999.99 元，最多两位小数。
2. 净消费 = 原消费 − 累计退款。退款扣减原消费日期的统计；这是消费账本，不是按实际资金流入日期记录的现金流账本。
3. 周从周一到周日；月和年使用自然月、自然年，支持闰年及跨年周。
4. 当前周期日均按已过自然日计算，历史周期按全部自然日计算，包括无消费的日期。
5. 日期分组小计按当天的完整筛选结果计算，即便列表尚未加载完，也不会少算金额。
6. 完全退款的记录仍计入消费笔数，仍可从明细查询，分类占比按净消费计算。
7. 记账日期范围为 2000 年起至今天，不支持未来消费。默认分类及支付方式参考最近修改过的记录。
8. 月预算设置对所有月份采用同一金额，暂不提供每月独立预算历史。

## 导出和恢复

「我的 → 导出与备份」：

- **CSV**：生成后使用微信文件发送面板保存到自己的文件传输助手或聊天，用于 Excel 阅读；不能从 CSV 恢复。
- **JSON**：发送并保存完整备份。请在设备之外保存文件；只生成设备内文件不等于完成外部备份。
- **恢复**：先将 JSON 文件发到微信聊天，再从文件选择器选取。备份校验通过并确认后，整体替换当前账本，不做合并。
- **恢复导入前副本**：可返回最近一次导入前的数据。导入后新记的账单不会包含在该副本中，操作前会确认。

设备内生成的文件名固定为 `xiaorizhang-bills.csv` 和 `xiaorizhang-backup.json`，每次更新同名文件，避免重复导出占用空间。外部保存的副本请自行管理。

开发者工具的文件选择/发送能力可能受环境限制，JSON 文件导入和发送需要真机验收。取消发送不会更新「最近成功发送备份」时间。这个时间表示微信文件发送 API 返回成功，不表示文件已永久保存。

## 数据保存与限制

- 数据通过微信本地存储保存在当前设备。换手机、清理小程序数据等情况可能导致本地数据不可用，事先导出 JSON 备份。
- 主账本在一个存储键内写入，写入失败时保留上次成功的数据，并显示错误，不显示保存成功。
- 数据结构损坏时不自动重置，页面提供备份恢复入口。
- 本地存储有平台容量限制，实际可保存的记录数取决于备注长度和设备存储条件。接近容量上限的写入会报错，可先导出备份；本版不提供云同步或历史归档。
- 当前结构最多校验 40 个分类、50,000 笔记录，文件选择上限 8 MB。这些是结构/文件校验上限，不代表平台一定能存下对应数量。
- JSON/CSV 是可读明文文件，包含你的消费和备注。备份文件请按自己的隐私需要保存。

## 开发检查

在项目根目录运行（推荐 Node.js 18 或更新版本）：

```sh
npm test
npm run check
```

若安装了微信开发者工具，可直接使用其附带的编译器检查全部模板与样式：

```sh
node scripts/native-check.js "微信开发者工具安装目录/code/package.nw/node_modules/wcc-exec"
```

`native-check.js` 只使用本地编译器，不启动 GUI、不上传项目。它不能替代模拟器渲染或真机验收。

## 真机验收清单

1. 新增 0.10、0.20 两笔，同一天总计应为 0.30。
2. 补记其他日期，确认日/周/月/年的明细与总额一致。
3. 编辑一笔金额，再登记部分或全部退款，确认列表和统计更新。
4. 新增分类，记账后删除该分类并迁移，确认历史金额不变。
5. 导出 CSV 检查中文、金额与备注；发送 JSON，再选取并恢复，确认账单、分类、预算一致。
6. 取消文件选择及文件发送，确认账本不变；恢复导入前副本，确认数据回退。
7. 关闭并重新进入小程序，确认本地账单仍在。

第一版不包含云端同步、自动读取微信支付账单、收入、多个账本和自动识别小票。
